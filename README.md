# דשבורד שלי – PWA (עובד אופליין)

## קבצים
- `index.html` – הדשבורד (כל הקוד והעיצוב)
- `sw.js` – Service Worker (מטמון + עבודה אופליין + עדכון אוטומטי)
- `manifest.webmanifest` + `icon-*.png` + `apple-touch-icon.png` – התקנה כאפליקציה
- `search-drive.html` – חלון החיפוש ב-Google Drive
- `logo.png` – הלוגו

## העלאה לאירוח (בחר אחת, כולן חינמיות)
**Netlify (הכי פשוט, בלי חשבון Git):** היכנס ל-app.netlify.com/drop וגרור לשם את *תיקיית* הקבצים (אחרי פריסת ה-ZIP).
**Cloudflare Pages:** Workers & Pages ← Create ← Pages ← Upload assets, וגרור את התיקייה.
**GitHub Pages:** צור repository, העלה את הקבצים, ואז Settings ← Pages ← Deploy from branch ← main.

חובה HTTPS (כל השירותים למעלה נותנים אותו אוטומטית). הכתובת שתקבל היא הכתובת של הדשבורד.

## שימוש
1. פתח את הכתובת פעם אחת עם אינטרנט בכל מכשיר – הקוד והנתונים נשמרים.
2. התקן: בכרום/אדג' – אייקון ההתקנה בשורת הכתובת; באנדרואיד – "הוסף למסך הבית"; ב-iPhone – שיתוף ← "הוסף למסך הבית".
3. מכאן הוא נפתח גם בטיסה / ללא רשת.

## עדכונים
- **נתונים:** משנים בגיליון, והדשבורד מתעדכן ברקע בכל פתיחה (ובחזרה לחלון).
- **קוד:** מעלים מחדש את הקבצים. בפתיחה הבאה האפליקציה מגישה מיד את הגרסה השמורה, מושכת את החדשה ברקע, ומרעננת את עצמה אוטומטית. אין צורך לנקות מטמון ואין צורך להעלות מספר גרסה.
  (שנה `CACHE_VERSION` ב-`sw.js` רק כדי לאלץ ניקוי מלא של המטמון.)

## התנהגות לפי האיפיון
- עמודה E: מוצג רק "כן" או ריק. כל ערך אחר מסתיר את השורה.
- עמודה F: קטגוריה נפתחת אם לפחות שורה אחת בה ריקה או "פתוח".
- שורה בלי עמודה A משויכת לעמוד "ראשי" (אפשר לשנות ב-`DEFAULT_PAGE`).
- שורה בלי URL מוצגת כמפריד/כותרת משנה בולטת.
- אם הגיליון מחזיר שגיאה או נתונים ריקים, הנתונים השמורים לא נדרסים.
